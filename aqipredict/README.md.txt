# 🌍 AQI Predictor & Health Advisor

A Machine Learning-based web app to predict Air Quality Index (AQI) using pollutant values.

## 🚀 Features
- Predict AQI using ML model
- Health advice based on AQI
- Historical AQI trends
- City-wise comparison

## 🛠️ Tech Stack
- Python
- Streamlit
- Machine Learning (Scikit-learn)
- Pandas, NumPy

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run aqi_dashboard5.py
